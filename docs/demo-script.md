# Demo script — target 2:40

## 0:00–0:15 — The promise

On screen: Quampute's Spark page and the visible “13 WebMCP tools are ready” banner.

Voiceover: “This is MOTH FORGE: QUAMPUTE. The creator gives it the part only they can know. Their agent carries the labor of consequence—on the same screen, without taking over the decisions that belong to them.”

## 0:15–0:35 — The problem

On screen: briefly show the six-stage rail and versioned Forge anchor.

Voiceover: “Deep characters and worlds do not fit in one prompt. They involve sources, contradictions, hundreds of questions, private intent, and downstream runtime rules. Forms make the creator do all the work. Chat alone loses the workbench.”

## 0:35–1:05 — Shared Spark

Prompt ChatGPT: “Inspect this Forge. Stage a character premise about a reserved museum registrar whose quiet kindness is mistaken for judgment, then tell me what still belongs to me.”

On screen: the agent calls `inspect_forge_studio`, then `set_forge_spark`. Show the concept appear and the activity ledger update.

Voiceover: “WebMCP gives the agent precise tools for the real application. It reads the pinned authority and stages a premise in the same editor I can touch. Nothing is saved yet.”

## 1:05–1:35 — Evidence and locks

Prompt ChatGPT: “Create the work order, attach this creator note as canon, and lock his reserve, quiet care, and comedy-through-social-misreading.”

On screen: `create_forge_project`, `add_forge_text_source`, and `update_forge_creator_locks`; show Sources and Locks as the page moves.

Voiceover: “The agent creates a private, revision-pinned work order, labels evidence by authority, and persists only the locks I asked for. It cannot silently promote inspiration into canon.”

## 1:35–2:05 — The human gate

Prompt ChatGPT: “Prepare the Quampute run.”

On screen: `prepare_forge_run`; in public mode acknowledge that it may restore deterministic demo state, then confirm it opens Review, reports zero model calls, and leaves active runs empty.

Voiceover: “This is the important boundary. The agent can inspect readiness and bring me to the gate. It cannot approve API charges or press the paid run button. Deletion and publication are human-only too.”

## 2:05–2:28 — Review, not surrender

Prompt ChatGPT: “Open the completed zero-cost example, inspect its review, and stage the reserved answer as ‘Leave first recognition open for play.’”

On screen: `open_completed_forge_demo`, `inspect_forge_review`, and `stage_forge_question_answer`. Show the explicit `$0` / no-model-call receipt, the staged answer, then edit it manually before saving.

Voiceover: “The public demo never spends an API credit. It opens seven synthetic resolutions tied to seven explicit routing slots, shows that no full tab or paid model pass was completed, and surfaces one creator-owned decision. The agent may stage an answer, but I see and control the commitment.”

## 2:28–2:40 — Close

On screen: Export and the collaboration ledger.

Voiceover: “Quampute is not an AI form filler. It is a division of creative labor by authority. The creator owns identity. The agent makes depth practical.”

## Recording notes

- Record at 1440p or 1080p with browser zoom at 100%.
- Keep the mouse still while agent tool calls run.
- Use one clean work order and short source text.
- Avoid showing API keys, private Forge prose, local paths, account IDs, or unrelated browser tabs.
- Keep the final upload public and under three minutes.
- Use the zero-cost completed example in the recording; do not configure or expose an API key.
